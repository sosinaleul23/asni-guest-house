Getting Started

Your first 5 minutes with the app

Open the app
Visit asni-guest-house.vercel.app in any modern browser (Chrome, Edge, Firefox, or Safari). The app loads instantly — no installation required.
Choose your role
Use the role dropdown in the top-right of the header to switch between Admin, Receptionist, and Guest views. The colour of the top bar and the visible menu items change instantly.
Explore the sidebar
The left sidebar is your main navigation. Click any item to jump to that module. On mobile, tap the menu icon to reveal it.
Try adding a record
Start with Rooms → click Add Room. Fill in the form and press Save Room. A green toast confirms the save and the new room appears in the table instantly.
Tip: The app works offline. If the network is down, you'll see "D1 Offline — Local Cache" in the header and everything still works with cached data.

Roles & Permissions

What each user type can see and do

Admin
  • Full dashboard access
  • Manage rooms, pricing, availability
  • Create & edit staff accounts
  • Full booking control
  • Financial reports & CSV export
  • SQL console & schema reset
Receptionist
  • Dashboard (no revenue details)
  • View & update room status
  • View users (no delete)
  • Create & manage bookings
  • Restaurant & kitchen orders
  • No financial reports
  • No SQL console access
Guest
  • Dashboard overview
  • View room availability
  • View own bookings
  • Browse menu & place orders
  • No user management
  • No financial data
Switching roles: Use the dropdown in the header. Your choice is remembered across sessions. If you switch to Guest while viewing a restricted page, you'll be automatically redirected to the Dashboard.

Dashboard Overview

Your at-a-glance command centre

The four KPI cards
The top row shows real-time metrics: Total Revenue (rooms + dining), Occupancy Rate (percentage of rooms currently occupied), Active Bookings, and Available Menu Items. These update automatically whenever you add, edit, or delete data.
Charts
The Revenue Trend line chart shows the last six months of combined income from bookings and orders. The Room Categories doughnut chart shows how your inventory splits across Standard, Deluxe, Executive Suite, and Family Suite room types.
Promotional banner
The coloured banner at the top of the dashboard rotates through your active promotional slides. Manage them under Ad Banners in the sidebar.

Managing Rooms

Add, edit, and track room inventory

Adding a new room
  1. Click Rooms in the sidebar.
  2. Click the Add Room button (top right).
  3. Fill in: Room Number, Capacity, Room Type, Price per Night, Status, and an optional Description.
  4. Press Save Room. The room appears in the table immediately.
Editing a room
Click the blue edit button on any room row. The form opens with all current values pre-filled. Modify anything and press Save Room.
Deleting a room
Click the red trash button. A confirmation dialog appears — because deleting a room also removes any bookings linked to it. Only Admin can delete.
Room statuses
Every room has one of four statuses, each with its own colour:
  • Available — ready for a new guest
  • Occupied — currently has a checked-in guest
  • Cleaning — being serviced after checkout
  • Maintenance — temporarily out of service

Bookings & Reservations

The heart of daily operations

Creating a booking
  1. Open the Bookings module.
  2. Click New Booking.
  3. Choose a room from the dropdown. The price per night is shown.
  4. Enter the guest's name and phone number.
  5. Pick check-in and check-out dates. The total is auto-calculated.
  6. Set status and press Save Booking.
Live room status grid
Above the bookings table is a coloured grid showing every room's current status. Green = Available, red = Occupied, amber = Cleaning, purple = Maintenance. Use it as a quick visual overview.
Automatic room status updates
When you set a booking's status to CheckedIn, the linked room automatically becomes Occupied. When you set it to CheckedOut or Cancelled, the room becomes Cleaning. This keeps room inventory in sync without manual updates.
Time-saver: Pick the check-in date first, then the check-out date. The total ETB is recalculated every time either date changes.

Restaurant & Orders

Menu management and kitchen workflow

The menu catalog
Every dish appears as a card showing its category, availability status, name, description, and price. Available dishes have a green badge; hidden dishes have a red badge and don't appear in the order cart.
Adding a dish
  1. In the Restaurant module, click Add Dish.
  2. Enter the name, category, and price in ETB.
  3. Tick Available on menu if it should be visible to guests.
  4. Add a short description and press Save Menu Item.
Placing an order
  1. Click the pink plus on any dish card. It's added to the cart.
  2. The cart badge in the header shows the current item count.
  3. Click the Cart button (top right).
  4. Choose Room Service or Restaurant Table.
  5. Pick the target room or table from the dropdown.
  6. Review the cart, then press Submit Order.
Kitchen orders queue
Below the menu is the live orders queue. Every submitted order appears here with its type, target, items summary, total, and status. Statuses progress: Pending → Preparing → Served. Use the edit button to advance an order's status, or the trash button to delete it.
Duplicate items: Adding the same dish twice increments its quantity in the cart instead of creating a duplicate line — much cleaner when ordering large tables.

Restaurant Tables

Seating inventory for the dining room

Three zones
Every table belongs to one of three zones: Indoor Main, Garden Patio, or Rooftop Lounge. Each has its own capacity and status (Available, Reserved, Occupied).
Adding a table
  1. Open the Restaurant Tables module.
  2. Click Add Table.
  3. Enter the table number (e.g. T-01), capacity, zone, and initial status.
  4. Press Save Table.
Integration: Every table you add here becomes a selectable target in the order cart dropdown. Add all your tables first, then place orders against them directly.

Users & Staff

Manage who can access the system

Registering a new user
  1. Open the Users & Staff module.
  2. Click Add User.
  3. Fill in Full Name, Email (must be unique), Phone, and Role.
  4. Press Save User.
The three roles
Choose admin for owners/managers, receptionist for front-desk staff, and guest for visitor accounts. See the Roles & Permissions section above for the exact capabilities of each.
Unique emails: Every user must have a distinct email address. If you try to save a duplicate, D1 rejects the insert and you'll see a red error toast.

Financial Reports

Live revenue ledger & CSV export

Revenue breakdown
Three summary cards at the top show Room Revenue, Restaurant Revenue, and the Grand Total. These are computed live from the bookings and orders tables — there is no separate ledger to maintain.
Transaction ledger
Below the summary, every transaction appears as a row with its reference number (B<id> for bookings, O<id> for orders), date, type, description, payer, and amount. Rows are sorted by date, most recent first.
CSV export
Click Export CSV to download the entire ledger as a spreadsheet-ready file. Open it in Excel, Google Sheets, or Numbers for further analysis.
Printing receipts
Click the print button on any row to open a branded receipt in a printable format. Press Ctrl+P (or Cmd+P on Mac) or click the Print button.

Ad Banners

Promotional slides for the dashboard

Creating a banner
  1. Open the Ad Banners module.
  2. Click Create Banner.
  3. Enter a short title (e.g. "Jimma Coffee Tour"), a description, and an offer tag.
  4. Choose a badge colour for the tag.
  5. Tick Active to make it visible on the dashboard.
  6. Press Save Banner.
Rotation: Only active banners appear on the dashboard. Currently the most recent active banner is featured in the hero area; you can hide a banner at any time by unticking the Active checkbox.

Cloudflare D1 SQL Console

Advanced database access — Admin only

Admin only. This module runs raw SQL against your production database. There is no undo. Only use it if you understand SQL.
Running a query
  1. Open the D1 SQL Console.
  2. Type your SQL into the editor (e.g. SELECT * FROM rooms;).
  3. Click Run Query. Results appear as formatted JSON below.
Useful query examples
-- List all occupied rooms
SELECT room_number, room_type FROM rooms WHERE status = 'Occupied';

-- Count bookings per room
SELECT room_id, COUNT(*) as total FROM bookings GROUP BY room_id;

-- Today's orders
SELECT * FROM orders WHERE DATE(created_at) = DATE('now');
Resetting the schema
The Reset Schema button wipes all tables and re-creates them with the original column definitions. All data is lost. Use this only when you want to start fresh — for example, after a demo or test session.

Themes: Dark & Light

Comfort for day and night shifts

How to toggle
Click the moon / sun icon in the header. The entire app — panels, tables, modals, forms, charts, and toasts — flips instantly between dark and light.
Remembered across visits
Your theme preference is saved in your browser. When you return to the app, the same theme loads automatically before the first paint — no flash.
When to use each
Dark theme is the default and best for evening or night shifts — it reduces eye strain in dim lighting. Light theme works best during daytime and for printing or screenshots.

Languages: English & አማርኛ

Switch the entire interface instantly

How to switch
Click the language button in the header. It cycles between EN (English) and አማ (Amharic). Every label, table header, form field, toast, and modal is translated.
What gets translated
  • All navigation and page titles
  • Buttons, table headers, form labels
  • Room types, statuses, categories, zones
  • Toast notifications and error messages
  • Receipts and printed documents
  • Chart legends and month names
Database stays English: The values stored in the database (room statuses, categories, etc.) remain in English. Translation happens only at display time, so your data stays consistent regardless of the interface language.

Frequently Asked Questions

Answers to the most common questions

Is my data saved automatically?
Yes. Every time you save a form (room, booking, dish, etc.), the change is sent immediately to the Cloudflare D1 database. There is no separate "Save" step or draft state.
Can I use the app offline?
Partially. If the network is down, the header badge changes to "D1 Offline — Local Cache" and the app loads your last cached data. You can still view everything. However, changes you make while offline won't sync back to the server — they stay only in your browser.
Why can't I see the SQL Console?
The SQL Console is restricted to the Admin role. If you're viewing as Receptionist or Guest, the menu item is hidden. Switch roles via the dropdown in the header to access it.
Can I undo a delete?
No. Deletions are permanent. The confirmation dialog exists to prevent accidents, but once you confirm, the record is gone from the D1 database. If you've made a mistake, you'll need to re-enter the data manually.
How do I know if a save worked?
A green toast appears in the bottom-right corner with a checkmark icon and a message like "Added Room 105". If something fails, you'll see a red toast with the error message instead.
Can I add a third language?
Yes — this is a developer task. The app's translation dictionary lives in app.js under T.en and T.am. To add a new language (e.g. Afaan Oromoo), add a T.om key with all the same translation keys. The language button would then cycle EN → አማ → OM.
What happens if the internet drops mid-save?
The save will fail and you'll see a red error toast. The form stays open so you can retry once the connection is restored. Nothing is half-saved — D1 transactions are atomic.
Who can see the financial reports?
Only Admins. The Financial Reports module is completely hidden from Receptionists and Guests. In a production system this would also be enforced at the API level.

Common Issues

Quick fixes for frequent problems

Header says "D1 Offline"
Cause: The Cloudflare Worker API is unreachable. Fix: Check your internet connection. Try clicking the refresh button in the header. If it persists, the API might be temporarily down — wait a few minutes and try again.
Red error toast after saving
Cause: The database rejected the save — usually a duplicate value (room number, email) or a missing required field. Fix: Read the error message in the toast. Common issues: room numbers must be unique; email addresses must be unique; guest names, phone numbers, and dates are required for bookings.
Sidebar won't open on mobile
Fix: Tap the menu icon in the top-left corner of the header. If it still won't open, refresh the page. On very small screens, the sidebar slides in from the left as an overlay — tap outside it to close.
Charts are blank
Cause: Usually a browser issue — Chart.js failed to load from the CDN. Fix: Hard-refresh the page (Ctrl+Shift+R). If it persists, check that your network isn't blocking cdn.jsdelivr.net.
"D1 must be online" message
Cause: You tried to run a SQL query or reset the schema while the app was in offline mode. Fix: Reconnect to the internet and refresh. Only online mode can execute raw SQL or reset the schema.
Theme won't stick
Cause: Your browser may be blocking localStorage (private browsing mode or strict cookie settings). Fix: Allow site data for the app's domain in your browser settings, or exit private browsing.
